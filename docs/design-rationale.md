# Design rationale

Why the folio looks the way it does. The brand kit in [brand-kit.md](brand-kit.md) holds the measurements; this
document holds the reasons.

## The name

The folio is called *The Raven's Ledger*. A ledger is a book of entries kept in order, each one dated and
accountable, and that is the argument the folio makes: every feature is traced to a source and every modification
to a test. The raven is the character's bird, and it stands for the black-on-black palette without naming a
television programme in the masthead. Eighteen characters, so it fits the same masthead geometry as a twenty
character wordmark with room to spare.

## Period frame, modern page

The garment is a 2022 screen costume corrected through three periods, 1905, 1926 and 1955, and the folio borrows
one page convention from that span: the engraved double rule under a masthead, a heavy line over a hairline, which printed ephemera used
to separate the head of a page from its content. Everything above the rule is identity; everything below it is
content. That division never moves across the twelve pages, and it is what makes them read as one document.

Nothing else on the page is period pastiche. The grid is a modern six-column grid, the tables are plain, and the
type is set to the NESA floor of 12 pt with a larger body so a marker never has to squint.

## Two faces, one job each

Fraunces Black is the display face, used only in the wordmark and section titles. It is a fat face, the heavy
high-contrast display type of the 1820s to 1900s, so the folio's own title type is arguing the same historical
case the pages argue. PT Serif is the text face for every word a marker reads. It has a larger body than Times at
the same point size, so 12 pt PT Serif clears the NESA floor with room to spare. The kit has no style below 12 pt.
When a page is crowded, the only fix is to cut words.

## Black and white, then four colours

The garment has no colour, and selected plates print in black and white in the manner of the 1964 series. The
folio therefore cannot use colour to decorate. It uses colour to navigate: each of the four NESA sections has its
own colourway, slate, bone, ash and wine, at the same value so they read as one family. A marker turning pages
sees the section change at the masthead before reading a word.

Area colours are fill and rule colours. They are never text colours. Ink sits only on the palest tones, the
masthead field and the table cell tint. That one rule means the colour system can never damage legibility. The
single exception is measured: the last clause of the closing statement is set in the chapter's `emph` token, the
accent mixed 80 per cent towards ink, and its contrast ratio is written in the stylesheet.

The two brand colours are sampled from the garment: `slate` from the tulle where it catches light, `wine` from
the jet beads under warm light. Slate is the rule under the wordmark. Wine is the NESA-designated second colour
that marks pattern modifications on page 7, so it carries meaning and is never used for decoration.

## Plates and drawings

Every source image and sketch sits in a double-ruled plate with four corner dots in the chapter colour, the way
period books mounted engravings. The frame does the historical work so a mixed set of source photographs reads as
one considered set. Production drawings on pages 6 to 8 sit in a plain single box with no dots, because NESA asks
for scaled line drawings with a key and the designated second colour only, and decorative framing pulls against
that. Filled numbered circles mark source plates; outlined circles with a leader mark callouts into my own
drawing. Filled means someone else's picture, outlined means mine.

## The three statements

Three passages carry the argument and are set as a set. The opening statement on page 1 makes the promise: an
evidence trail. The final justification on page 5 shows the promise being kept while the design is chosen. The
closing statement on page 12 says that it was. Same size, same measure, and the same ornamented rule at both
ends, so the folio opens and shuts on one device. Page 1 is set regular, because it has only made a promise. Page
12 is bold italic, because it has twelve pages of evidence behind it.
