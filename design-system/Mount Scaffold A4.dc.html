Using this sheet

Print at 100% / Actual size with margins set to None, then measure the bar at the foot. It has to read 100 mm end to end. If it is short, the printer scaled the sheet and nothing cut against it will fit.

Each outline is one mount on the A3 page: 34.9 × 28.5 mm across the rule, four to a block, 4 mm apart, in the same 82.3 mm frame the folio prints.

Trim samples a whisker inside the rule so no raw edge shows past it, and write the number on the back before it leaves the sheet.

Print-scale check. This bar is 100 mm end to end and each band is 10 mm. Measure it before cutting anything.
